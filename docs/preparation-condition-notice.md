# 기본조건 변경 안내와 진입 화면 정렬

2026-11-10 FE 후속 수정이다. BE·AI·API 규격은 변경하지 않는다. 서버·브라우저를 실행하지 않고 사용자가 기존 `run.py`로 최종 검수한다.

## 기본조건 변경 안내

이전에는 개인 입력이 깨끗하면 공통 버전 변경 후 자동 조회를 수행했고, 조회 성공이 일반 상태 문구를 비워 변경 안내가 사라졌다. 이제 공통 버전의 변경 관측과 개인 데이터 조회 상태를 분리한다.

- 첫 진입과 최초 기본조건 저장은 기준 버전만 설정한다.
- 이미 저장된 공통 조건의 버전이 증가하면 `내 취향` 영역에 변경 안내를 표시한다. 방장의 자기 저장과 다른 참여자 화면의 갱신에 같은 기준을 적용한다.
- 입력 수정 여부, 개인 조회·재조회, 저장·분석·실패, 검토 체크만으로 안내가 사라지지 않는다.
- 안내는 최신 조건에서 명시적 `준비 완료` 요청이 성공해야 해제한다. 응답 유실이나 다른 탭의 확인 뒤 재조회가 해당 최신 버전의 서버 `confirmed`를 검증한 경우도 완료로 인정한다. 일반 `writing` 조회나 오래된·관측하지 않은 버전은 최신 안내를 해제하지 않는다.
- 다른 여행방으로 바뀌면 관측 기준을 초기화하며, 권한 상실 상태에서는 개인 화면과 안내를 숨긴다. 같은 방의 일시적 로딩은 안내를 초기화하지 않는다.
- 빠르게 연속 변경되거나 최초 개인 GET이 오래된 조건을 반환해도 조회 중 상태에 갇히지 않고 최신 조건 재조회/복구 경로를 제공한다.

이 안내는 개인 취향을 삭제하거나 자동 확정하지 않는다. 공개 참여자 준비 상태와 저장 버전·권한 검사는 기존 서버 규칙을 유지한다. 상태 추적은 현재 화면 세션의 공통 버전 관측을 사용하며, 새 브라우저 진입에서 과거 변경 이력을 추정하지 않는다.

## 정렬과 선택 표시

시작 화면의 생성·참여 폼에서 라벨·도움말·입력의 행 구조를 통일하고 스크롤바 출현에 따른 가로 이동을 줄인다. 제출 로딩은 글자만 바꿔 기존 버튼 아이콘과 폭을 유지한다. 기존 사진·색·버튼 형태·입력 유효성·생성/참여 흐름은 유지한다.

충북 전체와 개별 지역 카드의 체크 아이콘은 제거한다. 실제 선택, 테두리·배경 강조와 `aria-pressed`는 유지한다. 개인 준비 확인 체크박스는 변경하지 않는다.
