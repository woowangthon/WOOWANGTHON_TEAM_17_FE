# 초기 구성 결정

2026-11-03

- React + TypeScript + Vite + Tailwind, npm과 단일 package-lock.json을 사용한다.
- Node 24.x를 package.json engines에 기록하고 실제 개발 기준은 README에 적는다. 사용자 선택에 따라 .node-version은 추가하지 않는다.
- 초기 범위는 실행 환경·공통 UI 확인 화면·팀 문서·에이전트 설정·이슈/PR 양식이다. 여행 기능·API·배포는 별도 작업이다.
- 공통 UI는 소스로 관리한다. 기존 Mantine 예제와 원본 노션 내보내기·압축파일은 레포에 복사하지 않는다.
- 개인 원문 본인 전용은 UI 설계의 초기 기준이다. 방장 접근·인증·서버 권한과 익명성 정책은 백엔드/팀과 확정해야 하며 UI 숨김만으로 보호를 구현했다고 하지 않는다.
- GitHub CI는 제외한다. 로컬 검사와 필요한 브라우저 검증 결과를 PR에 기록한다.
- 향후 기능·버그 작업은 이슈부터 PR 제출까지 진행하고 사람은 리뷰·병합한다. 초기 설정 전달만 사용자가 파일·검증 결과를 확인한 후 커밋·푸시한다. 이 일회성 확인을 모든 작업의 승인 규칙으로 확대하지 않는다.
- 모델 기본값은 원본 초안의 Astra medium / Luna high를 유지한다. 계정 접근과 클라이언트 설정 적용은 별도로 검증한다.
