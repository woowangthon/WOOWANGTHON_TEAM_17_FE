색·간격·반경은 src/styles/theme.css에서 정의한다. 버튼·입력·모달을 공통 컴포넌트로 재사용한다. 밝은 연두 버튼은 짙은 글자, 오류는 빨강, 주의는 노랑, 비활성은 회색으로 구분한다.

|화면|중요한 동작|
|---|---|
|방 진입|생성·코드 참여·기존 참여 재접속|
|여행 준비|내 다음 행동·참여 상태·생성 불가 사유|
|개인 조건|원문과 해석 비교·수정·직접 확정|
|일정|목록·지도·선택 상세 동기화|
|수정·복원|비교·재검사·확인·새 버전 저장|

공통 조건 변경 시 재확인이 필요하다. 개인 원문은 공동 화면에서 숨긴다. 예산은 전체 총액과 추정값을 구분한다. UI의 비활성만으로 권한·저장 가능 여부를 판단하지 않는다.

노션에는 화면 보드와 이 문서 링크를 둔다. 구현 변경과 기준 변경은 같은 PR에서 관리한다. 기존 데스크톱 시안은 화면 구조 참고용이며 초기 앱이 구현된 것은 아니다.
