# 캔버스 편집 일정 보기

사이드바의 `여행 일정`은 생성된 원본 대신 공동 캔버스의 최신 편집 문서를 읽는다. 캔버스의 현재 저장 대기 편집도 목록과 지도에 반영하며, 날짜별 장소·선택 상세는 실제 캔버스 노드 ID와 연결을 기준으로 동기화한다. 캔버스의 순서 연결은 `GET /api/v1/trips/{tripId}/canvas/route`로 다시 확인한다. 기존 계약의 지도 경로 geometry 옵트인 헤더를 사용하고, 응답의 source/target·conditionsVersion·mode가 현재 간선과 일치하는지 기존 parser가 검증한다. 새 endpoint나 서버 데이터는 추가하지 않는다.

지도에는 응답이 `verified`이고 실제 경로 좌표가 검증된 간선만 그린다. 오래된 캐시, 미확인 응답, 조회 실패, 좌표 없는 verified 응답은 선을 만들지 않는다. 사용자별 브라우저 간선 이동 설정은 공통 이동수단보다 우선한다. 직접 입력한 시간은 자동 확인 시간과 구별해 목록에 표시한다. 지도 좌표가 없는 장소도 번호 선택 항목·장소 목록·상세는 유지한다.

현재 캔버스에는 비용 합계 계산·검증 결과가 없으므로 비용을 총액으로 집계하지 않는다. 가져온 방문 시각은 생성 당시 예상이며 캔버스 편집 뒤 다시 계산되지 않았음을 안내한다. 연결되지 않은 코스는 별도 묶음으로 보여주며 임의 선으로 연결하지 않는다. 장소 상세 조회 실패는 장소별 재시도를 제공한다. 지도 SDK 오류 시 번호 선택 화면으로 대체하며 연결선은 표시하지 않는다.

## 검증 범위

`tests/canvas-itinerary.test.mjs`는 연결 재배치·해제·삭제·날짜 이동, 고립된 후보와 댓글 제외, 연결 후보·중복 방문, edge ID에 따른 verified geometry만 표시, 누락 좌표와 잘못된 geometry를 검사한다. 실제 Kakao 지도/API 결과와 브라우저 반응형 검수는 별도 UI 검증에 기록한다.

### 2026-11-12 실행 결과

- `npm run check`의 typecheck·lint·build 통과, `npm test` 198개 통과. lint 오류 0개, 경고 27개(기존 파일 25개·새 일정 컴포넌트 effect 관련 2개)는 남는다.
- 실행 중인 기존 `run.py`의 `http://127.0.0.1:8017`에서 실제 테스트 방의 장소 5개·도로 geometry 4개와 Kakao 지도 타일·마커를 확인했다. 목록·마커·번호 선택이 같은 상세를 표시한다.
- 기존 브라우저의 구간 설정으로 돌집식당→고수동굴을 차량 4분에서 도보 20분으로 바꾸고, 해당 수단의 실제 geometry가 지도에 표시되는 것을 확인했다. 검수 후 공통 차량 설정으로 복원했으며 공유 DB 문서는 변경하지 않았다.
- 외부 API/DB가 차단된 별도 예시 서버에서 1440×1000·390×844의 날짜 전환·키보드 선택·메뉴 Escape와 초점 복귀·가로 넘침 없음, SDK 실패 시 선 0개를 확인했다. 캔버스 연결 해제→분리 목록 반영→실행 취소, 장소 삭제 뒤 빈 날짜 안내도 확인했다.
- 독립 Sol high 코드 검토의 방문 시각 안내·장소 상세 오류 표시 지적을 반영했고 남은 P1/P2는 없다. 신규 BE/AI/DB 변경은 없으며 실제 공유 방의 장소 삭제·재배치는 검수하지 않았다. 편집 회귀는 예시 문서에서 수행했다.
