# 캔버스 편집 일정 보기

현재 표시 기준은 마지막 `2026-11-14 체류·이동 시간과 지도 위치 조작` 절이다. 앞선 준비 화면 양식·사진 중심·지도 아래 상세 및 단일 상세 펼침 시안은 당시 기록으로 구분한다. 사용자 화면 검수는 기존 BE `run.py`로 진행한다.

사이드바의 `여행 종합`은 생성된 원본 대신 공동 캔버스의 최신 편집 문서를 읽는다. 기존 `view=itinerary` 주소는 유지한다. 캔버스의 현재 저장 대기 편집도 목록과 지도에 반영하며, 날짜별 장소·선택 상세는 실제 캔버스 노드 ID와 연결을 기준으로 동기화한다. 캔버스의 순서 연결은 `GET /api/v1/trips/{tripId}/canvas/route`로 다시 확인한다. 기존 계약의 지도 경로 geometry 옵트인 헤더를 사용하고, 응답의 source/target·conditionsVersion·mode가 현재 간선과 일치하는지 기존 parser가 검증한다. 새 endpoint나 서버 데이터는 추가하지 않는다.

지도에는 응답이 `verified`이고 실제 경로 좌표가 검증된 간선만 그린다. 오래된 캐시, 미확인 응답, 조회 실패, 좌표 없는 verified 응답은 선을 만들지 않는다. 사용자별 브라우저 간선 이동 설정은 공통 이동수단보다 우선한다. 직접 입력한 시간은 자동 확인 시간과 구별해 목록에 표시한다. 지도 좌표가 없는 장소도 장소 목록·상세는 유지한다.

현재 캔버스에는 비용 합계 계산·검증 결과가 없으므로 비용을 총액으로 집계하지 않는다. 가져온 방문 시각은 생성 당시 예상이며 캔버스 편집 뒤 다시 계산되지 않았음을 안내한다. 연결되지 않은 코스는 별도 묶음으로 보여주며 임의 선으로 연결하지 않는다. 장소 상세 조회 실패는 장소별 재시도를 제공한다. 종합 화면의 지도 SDK 오류·좌표 누락은 평문 상태로 표시하고 임의 번호 배치나 연결선을 만들지 않는다. 기본 생성 화면의 지도 표시 방식은 별도로 유지한다.
