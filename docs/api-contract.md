# API 계약 — 합의 전

실제 endpoint·요청·응답은 아직 정하지 않았다. 아래 항목을 백엔드와 합의한 뒤 구현한다.

- 방 생성·참여·재접속과 참여 식별 방식.
- 공통 조건·개인 원문·해석·확정 데이터 형식.
- 생성 가능 상태와 실패·재시도 방식.
- 일정·장소·이동·비용·정보 출처 형식.
- 수정 초안·검사·적용·동시 저장 충돌·복원 계약.
- 개인별 조회·수정 권한과 공통 오류 응답.

각 API에 method/path, 인증, 요청·응답 예시, 오류, 버전 정책을 기록한다. OpenAPI가 제공되면 해당 문서의 버전과 링크를 기준으로 삼는다. 합의 전 UI 개발은 mocks로 구분한다.
