# 백엔드 채팅에 붙여 넣을 요청

아래 요청을 `WOOWANGTHON_TEAM_17_BE`를 연 Codex 채팅에 입력한다. 이 FE 작업에서 BE 파일이나 DB는 변경하지 않았다. API 상세 원본은 Notion이며 이 문서는 실행 요청문이다.

```text
여행방 생성 이후의 ‘여행 준비’와 ‘내 취향·제약’ 화면을 연결할 백엔드를 구현해줘.

FE는 codex/15-room-dashboard 브랜치에 두 화면을 구현했어. 지금 방 정보/초대 코드는 기존 reconnect API이고, 공통 조건·개인 원문·직접 확정은 메모리에만 있는 UI 초안이야. 백엔드 구현 후 FE에서 신규 API 연결이 별도로 필요해.

먼저 이 저장소 AGENTS.md와 아래 공용 API 계약을 읽어줘.
- 여행 준비·개인 조건(구현 요청): https://app.notion.com/p/412e977e49088197b345d73603c6a27f
- 공통 규칙: https://app.notion.com/p/40ee977e49088189b512e6e817984d48
- 기존 여행방 시작: https://app.notion.com/p/40ee977e49088105a9b4ce4df0aef6f8

계약에 있는 6개 API를 구현해줘.
1. 여행 준비 정보와 공개 참여자 준비 상태 조회
2. 방장만 공통 조건 저장: 지역·날짜·예정 인원·전체 예산·교통·출발/복귀 장소·숙박·고정 일정
3. 본인 개인 원문/정리 조건 조회
4. 본인 원문/좋아하는 활동/회피 요소·중요도/음식·중요도/걷기 답변 저장
5. 기존 AI 패키지를 서버 서비스로 연결해 본인 원문 해석 제안 반환. 자동 저장·확정 금지
6. 현재 공통/개인 버전을 확인한 뒤 본인이 직접 확정

기존 HttpOnly 기기 세션과 membership 인증을 재사용하고, 방장도 다른 사람의 개인 원문·해석을 읽을 수 없게 해줘. 공개 준비 상태에는 닉네임·역할·writing/confirmed만 포함해줘.

버전 충돌 409, 공통 조건 변경 시 전원 확정 무효화, 개인 변경 시 본인 확정 무효화, AI 요청 중 내용 변경 시 오래된 제안 차단을 트랜잭션과 테스트로 보장해줘. 새로고침·서버 재시작 후 데이터가 복원되어야 해.

현재 FE 자유 입력과 DB의 지역 코드/좌표/숙박 boolean/고정 일정 배열/교통 enum 차이를 확인해줘. 계약의 v1 텍스트 준비 문서를 별도로 보존하고 기존 구조화 필드에 임의 변환·덮어쓰기를 하지 마. 필요한 additive migration과 rollback을 PR에 제시해줘. 공용 DB 초기화·자동 migration 적용은 하지 마.

격리 테스트 DB와 AI stub으로 권한·입력·저장·재시도·버전 충돌·동시 확정·개인정보 비노출·AI 실패 및 지연을 검증해줘. 실제 AI 호출이나 공용 데이터 변경 없이 가능한 검사를 먼저 마쳐줘.

BE 별도 이슈/브랜치/PR로 제출하고, Notion에는 구현 상태·BE PR·실제 검증 결과만 갱신해줘. 규격 모순이나 기존 AI 패키지 출력 계약의 제약이 있으면 FE에 구체적으로 알려줘. 실제 일정 생성·지도·변경 이력은 이번 범위 밖이야.
```
